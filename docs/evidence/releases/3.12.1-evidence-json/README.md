All 11 source hashes, including the shared parser, remain stable through disposal. [Before-loss](counter-before-loss.json) and [after-loss](counter-after-loss.json) artifacts retain the distinct observed `0→0→0` and `0→1→1` values. Network-blocked offline inspection passes.
- [Client build manifest](client-build.json), measured at 17:17:59 UTC, includes the shared parser in the actual reachable module graph. All 16 maintained files match generated bytes. Its historical 3.10.0 baseline and 3.6.0 recording pins remain unchanged; it does not measure browser loading time.

Local validation passes 295 Vitest tests across 24 files, 18 counter codec Node tests, eight asset-verifier Node tests, formatting, TypeScript, build and both deployment dry-runs. Duplicate-name regressions reproduce last-key-wins parsing that preserves the original canonical hash, then require safe rejection at archive and raw frame/sample boundaries. Valid pinned archives keep their hashes. [ADR 014](../../../adr/014-unique-evidence-json.md) explains the stricter format rule.

These local artifacts establish neither source authenticity, complete history, command attribution under arbitrary traffic, rendered interaction, production failure behavior, cost nor external adoption. Deployment and live verification are recorded separately in [validation](../../VALIDATION.md).
